本文件夹用于存放作品的完整源代码、训练好的模型权重、依赖配置文件以及核心知识库文件。

文件说明：
- best_efficientnet_b0.pth：训练好的EfficientNet-B0模型权重文件，用于皮肤病图像分类推理。
- auth_ui.py：用户认证界面模块，实现注册、登录对话框功能。
- backend.py：后端服务主程序（FastAPI），提供图像检测、智能问答、历史记录等API接口。
- main.py：客户端主程序（PyQt5），实现图像上传、检测结果展示、问诊交互及语音输入功能。
- train2.ipynb：模型训练Jupyter Notebook，包含数据加载、模型定义、训练策略及评估代码。
- knowledge.py：简版知识库，包含22类皮肤病的基础信息（简介、症状、病因、建议、用药）。
- knowledge1.py：详版知识库，提供各类皮肤病的详细临床描述（病因机制、病理特征、鉴别诊断等）。
- knowledge2.json：递进式问答库，采用“疾病→维度→具体问题”三级结构，用于智能问诊的预设问答对。
- requirement.txt：Python依赖包列表，用于快速搭建运行环境。
